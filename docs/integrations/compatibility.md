# Compatibility

The package targets Python 3.12 and resolves dependencies through uv. The validated
environment uses uv 0.12.15, Python 3.12.14, `langchain` 1.4.2, `langgraph` 1.2.12, and
`langgraph-xai` 0.1.0. The initial architecture requires `langgraph>=1.0` and
`langgraph-xai>=0.1.0`; Swarm and Deep Agents remain optional
example/integration dependencies. Exact resolved versions are recorded here.
